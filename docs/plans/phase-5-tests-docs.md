## Decisions on ambiguities

- The seeded published cluster takes the §9 title *Tracing recursive return values*; the live Claude run therefore produces clusters for the stack-unwinding and base-case groups, and the script publishes whichever one Claude returns (or falls back to the seeded cluster / manual grouping).
- `rooms.join` capacity is tested sequentially (convex-test runs one mutation at a time); the concurrent guarantee comes from Convex's serializable mutations, which is stated in the test name and README rather than simulated.
- Time control uses `vi.useFakeTimers({ toFake: ["Date"] })` + `vi.setSystemTime`; scheduled functions are never advanced, so `claude.clusterQuestions` is never loaded.
